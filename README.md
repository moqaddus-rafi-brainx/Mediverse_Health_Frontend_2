# Authentication and Patient Listing Features

This branch consist of code for the authentication pages(login,forget pass, reset pass ) and Patient Listing page.

## Key Features

- User Login
- The User will be able to resett the forget password.
- User can see a list of all the patients
- User can deleted Patients
- User can searh patients on the basis of name or Id.
 
#### Client

- React JS
- React-router-dom (To handle routing)
- Axios (for making api calls)
- Material UI & CSS Module (for User Interface)
- Apex Charts (to display payment history)
- Google Map
- Argon Dashboard Components

#### Server

- Express
- Mongoose
- JWT (For authentication)
- bcryptjs (for data encryption)
- Nodemailer (for sending invoice via email)
